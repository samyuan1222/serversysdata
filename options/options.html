How to Import Machine Stats

No API needed. Import directly from your company's machine stats portal.

  1. Open your machine stats portal (e.g. INTEGRIS) in the browser
  2. Search for your machine name on the portal page
  3. Click the Server Summary Bot extension icon
  4. Click "Import from Current Page"

The extension reads Machine Name, OS, Model, Location, AD, SCCM, McAfee, and OneSign data directly from the page.
